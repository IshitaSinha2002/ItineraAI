<h1>ItineraAI</h1>

<p>
  An AI-powered travel planning application built using ReactJS, FastAPI, LangChain, and Groq LLM.
</p>

<h2>Overview</h2>

<p>
ItineraAI is a full-stack AI application that generates intelligent and personalized travel itineraries based on:
</p>

<ul>
  <li>Destination</li>
  <li>Trip duration</li>
  <li>Budget</li>
  <li>Travel style</li>
  <li>User interests</li>
</ul>

<p>
The application uses Large Language Models through LangChain and Groq to create structured day-wise travel itineraries and visualize them using a modern travel dashboard interface.
</p>


<h2>Features</h2>

<ul>
  <li>AI-generated personalized travel itineraries</li>
  <li>LangChain-powered prompt workflow</li>
  <li>Groq LLM integration</li>
  <li>Modern ReactJS travel dashboard UI</li>
  <li>Day-wise itinerary generation</li>
  <li>Dynamic itinerary rendering</li>
  <li>Travel style customization</li>
  <li>Budget-based trip planning</li>
  <li>Structured JSON output parsing</li>
  <li>FastAPI backend architecture</li>
  <li>Responsive UI design</li>
</ul>

<h2>Application Workflow</h2>

<pre>
User Input
    ↓
React Frontend
    ↓
Fetch API Request
    ↓
FastAPI Backend
    ↓
LangChain Prompt Processing
    ↓
Groq LLM
    ↓
Structured Travel Itinerary
    ↓
Dynamic Itinerary Dashboard
</pre>
